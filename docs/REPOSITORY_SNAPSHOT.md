## 包含

1. 实际运行的所有模型代码快照，包括已修正/排除的历史版本。
2. 上游来源源码和原始许可证；嵌套Git元数据不收录。

6. 资源采样原始JSONL；其记录时段和共卡边界如实保留。
7. 结果导出脚本和数据资产状态说明。

本次结果采集开始时间以results/summary.json为准，当前导出包含1,877个评估点。发布过程中后续训练仍然继续，因此这是冻结快照，不是实时看板。

- Python虚拟环境及CUDA包实体；
- 模型权重、优化器快照、replay、训练/评估轨迹；
- 全部逐回合训练流水、TensorBoard大文件和大型数据；

Git结果保留所有已记录评估点与含损失/梯度的训练标量。只包含逐回合训练回报、数据集大小或计步的密集流水不重复上传，完整原件仍在服务器。JSON不支持的非有限训练标量导出为null，并保留其指标名称；R2I空正/负子集诊断可能产生定义内的NaN，不直接当成优化失败。

失败/排除项保留完整小日志或末尾记录，原始运行不会删除或改写。历史文档中的“当前”“下一步”按其时间戳解释，最新导航和结论见README与docs/RESULTS.md。

## 证据边界

当前全部seed0、固定阶段预算，不是完整论文复现。源方案里的we show/预期提升占位符仍未成为实验结论。服务器3时至14:44之间存在已记录的实际巡检缺口；不能因自动化设为一小时而宣称其间每次检查成功执行。

保存的检查点存在不等于训练成功。集成运行只用于验证真实更新、有限核心指标和保存，不作为主性能结果。原MCN二级复位初筛四格均接近随机，方法学习效果偏弱，E2因果链尚未建立。
