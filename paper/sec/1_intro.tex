\section{Introduction}
\label{sec:intro}

An agent that explores a house through a head-mounted camera sees a few square meters at a time.
To return to the kitchen, or to pick up the object it passed a minute ago, it must remember what it can no longer see.
World models provide this memory: they compress the history of observations and actions into a recurrent latent state, predict the future from it, and let the agent learn behavior in imagination~\cite{ha2018world,hafner2019planet,hafner2020dreamer,hafner2025dreamerv3}.
Recent world models remember for hundreds of steps~\cite{samsami2024r2i,deng2023s4wm}, and memory benchmarks measure how far~\cite{osband2020bsuite,morad2023popgym,pasukonis2023memorymaze}.

Embodied agents also run on batteries.
Spiking neural networks (SNNs) communicate with binary events, replace multiply-accumulates by accumulates, and run on neuromorphic processors at a fraction of the energy of dense networks~\cite{roy2019towards,davies2018loihi,orchard2021loihi2}.
Spiking neurons are dynamical systems with membrane and dendritic time constants, and these dynamics are widely credited with a capacity for temporal memory~\cite{bellec2018lsnn,zhang2024tclif,zheng2024dhsnn}.
Spiking-WM~\cite{sun2025spikingwm} builds a spiking world model on multi-compartment neurons whose dendrites are meant to integrate information over long timescales.

We find that spiking world models do not use this capacity: they forget within a few steps (\cref{fig:memory_length}).
On BSuite memory length, \swm does not recall a cue 8 steps back; recurrent LIF neurons stop at 8 steps and gated recurrent spiking neurons~\cite{qin2025grsn} at 16.
The cause is reset.
First, every environment step starts from cleared membrane potentials, the standard practice in spiking RL~\cite{tang2020popsan,liu2023dsqn,sun2025spikingwm}; only the binary spike output reaches the next step.
Second, a somatic spike resets the dendrites together with the soma, so a dendritic trace survives only until the neuron next fires.
Memory must therefore be re-encoded into spikes at every step, gradients cross a surrogate derivative at every step, and the time constants shape only the few simulation steps inside one environment step.
This explains the earlier observation that changing the time constants of \swm barely changes its performance~\cite{sun2025spikingwm}.
Long time constants do not help even without the resets: the Euler update writes input with gain $1/\tau$, so a compartment with a time constant of 128 simulation steps stores a cue at about one percent of the firing threshold.

We call this failure \emph{reset-induced amnesia} and test it causally (\cref{sec:amnesia}).
In a world-model probe that isolates memory from exploration, removing the dendritic reset or restoring the write gain has no effect while the step reset remains.
With persistent state the world model recalls cues 16 steps back, and adding the write gain extends this to 32 steps, learned faster than with a GRU core.
Conversely, clearing the dendrites of our own model at every step erases its memory.

These results give a design rule: memory should live in a state that no spike ever resets, and spikes should only carry information out of it.
We build \method from \emph{persistent dendritic neurons} (PDNs) that follow this rule (\cref{sec:method}).
A PDN keeps several linear dendritic channels across environment steps.
They are never reset and receive no spikes back from the soma, and their write gain is normalized so that channels with time constants from 1 to 1000 environment steps all store input at the same scale.
Integrator channels hold \emph{what} was seen.
Resonant channels, damped oscillators in the tradition of resonate-and-fire neurons~\cite{izhikevich2001resonate}, also encode \emph{when}, because their phase advances at every step.
The soma has no state: at each step it reads the dendrites and emits one binary spike, the only signal that leaves the neuron.
Graded state never crosses a synapse; it stays inside the neuron, as in neuromorphic cores with multi-variable neurons~\cite{orchard2021loihi2}.

We evaluate on memory benchmarks with published ANN protocols and on a non-memory control (\cref{sec:experiments}).
Of all models we train, spiking or ANN, \method is the only one that solves BSuite memory length 64, and it solves 101 steps under the protocol of R2I~\cite{samsami2024r2i}, where DreamerV3 fails beyond 51.
Its world model is the only one that recalls the card of exactly 32 steps ago in POPGym RepeatPrevious~\cite{morad2023popgym} (AUC 0.93; all others, DreamerV3 included, stay at chance).
It uses 2.9$\times$ less energy per step than DreamerV3.
Our contributions are:
\begin{itemize}
\item We identify reset-induced amnesia in spiking world models: the step reset, the dendritic reset, and a write gain tied to the time constant. We establish it with causal interventions.
\item We propose the persistent dendritic neuron, in which persistent, normalized integrator and resonant dendrites store memory and a stateless soma communicates by spikes, and build the spiking world model \method from it.
\item We give the first evaluation of spiking world models on standard memory benchmarks (BSuite memory length up to 101 steps, POPGym RepeatPrevious, Memory Maze), with DMC as a non-memory control and per-step energy accounting.
\end{itemize}
