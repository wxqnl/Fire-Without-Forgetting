\section{Related Work}
\label{sec:related}

\paragraph{World models and memory.}
Latent world models learn a recurrent state from observations and actions and train behavior in imagination~\cite{ha2018world,hafner2019planet,hafner2020dreamer,hafner2021dreamerv2,hafner2025dreamerv3}.
In partially observable tasks this state is the agent's memory, and the recurrent core sets how long it lasts: a GRU in the Dreamer family, attention over a finite context window in transformer world models~\cite{micheli2023iris,robine2023twm,zhang2023storm}, and a linear state space recurrence in S4WM~\cite{deng2023s4wm} and R2I~\cite{samsami2024r2i}.
With this recurrence, R2I solves memory tasks that DreamerV3 cannot on BSuite memory length~\cite{osband2020bsuite}, POPGym~\cite{morad2023popgym} and Memory Maze~\cite{pasukonis2023memorymaze}, and linear recurrences with decaying and rotating state also serve as memory cells in model-free RL~\cite{orvieto2023lru,voelker2019lmu,lu2023s5icrl,morad2023ffm}.
Probes of the learned state measure this memory apart from exploration and credit assignment~\cite{pasukonis2023memorymaze,wijmans2023maps,ni2023transformers}.
All these models are dense ANNs whose units pass graded state vectors from step to step.
In a spiking world model, neurons pass only binary spikes, so long-horizon memory has to be held inside the neurons themselves.

\paragraph{Spiking reinforcement learning and world models.}
Spiking actors and Q-networks~\cite{tang2020popsan,liu2023dsqn} run a feedforward SNN for a few simulation steps per environment step and clear it before the next step, which confines their state to a single environment step.
Recurrent spiking agents carry information across steps: GRSN~\cite{qin2025grsn} aligns a gated recurrent spiking neuron with environment time for model-free RL in POMDPs, and recurrent LIF networks have been trained end to end for model-based control~\cite{huebotter2025spiking}.
\swm~\cite{sun2025spikingwm} brings multicompartment neurons into the world model of DreamerV3 and evaluates it on DMC from pixels and on speech classification.
Its neurons are cleared at every environment step and its dendrites at every somatic spike, so their time constants act only within one step, and changing them barely changes its performance~\cite{sun2025spikingwm}.
These works evaluate control and classification; inside a world model on memory benchmarks, their cores remember at most 16 steps (\cref{sec:rl}), and \cref{sec:amnesia} traces this failure to reset amnesia.

\paragraph{Spiking neurons with long memory.}
Neuron models extend the memory of a spiking neuron with adaptive thresholds~\cite{bellec2018lsnn,yin2021adaptive}, two compartments~\cite{zhang2024tclif}, dendritic branches with heterogeneous time constants~\cite{zheng2024dhsnn} and resonate-and-fire dynamics~\cite{izhikevich2001resonate,higuchi2024brf,zhang2025drf}.
Removing the reset makes the membrane linear and parallelizable~\cite{fang2023psn}, and spiking state space layers attach spiking outputs to linear recurrences~\cite{shen2025spikingssm,bal2025pspikessm,fabre2025silif,stan2024learning}.
These models are trained and tested on offline sequence classification, where the network sees each sequence in full and is reset between samples.
A world model instead filters an unbounded stream one environment step at a time and continues its state in imagination; we run DH-SNN and TC-LIF in this setting as baselines.
\method is designed for this setting: its memory persists across environment steps in dendrites that no spike resets, its retention times are counted in environment steps, and its soma holds no state.
PDNs borrow two properties of biological neurons: dendrites act as computational subunits~\cite{london2005dendritic,poirazi2003pyramidal,larkum2013cellular,beniaguev2021single}, and many neurons resonate below threshold~\cite{hutcheon2000resonance}.
