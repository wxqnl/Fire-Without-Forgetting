\section{Related Work}
\label{sec:related}

\paragraph{World models and memory.}
Latent world models learn a recurrent state from observations and train behavior in imagination~\cite{ha2018world,hafner2019planet,hafner2020dreamer,hafner2021dreamerv2,hafner2025dreamerv3}.
Their memory is that of the recurrent core: a GRU in the Dreamer family, attention over a context window in transformer world models~\cite{micheli2023iris,robine2023twm,zhang2023storm}, and a state space recurrence in S4WM~\cite{deng2023s4wm} and R2I~\cite{samsami2024r2i}.
R2I solves memory tasks that DreamerV3 cannot, and we use its settings for BSuite memory length~\cite{osband2020bsuite} and POPGym~\cite{morad2023popgym}.
Memory Maze~\cite{pasukonis2023memorymaze} measures long-term memory in first-person 3D navigation with an offline probe of the world model state, in the spirit of probing the maps that navigation agents build~\cite{wijmans2023maps}.
Ni \etal~\cite{ni2023transformers} separate the length of memory from the length of credit assignment; our world model probes do the same by removing the policy.
All these models are dense ANNs.

\paragraph{Memory cells for RL.}
Dense memory cells built on linear recurrences with decaying, rotating state include the LRU~\cite{orvieto2023lru}, Legendre memory units~\cite{voelker2019lmu}, S5 layers for in-context RL~\cite{lu2023s5icrl}, and fast and forgetful memory, whose complex traces drift in phase with time~\cite{morad2023ffm}.
They pass graded vectors between units; a PDN keeps such state inside each spiking neuron, without gates, and sends only spikes.

\paragraph{Spiking reinforcement learning.}
Spiking actors and Q-networks~\cite{tang2020popsan,liu2023dsqn} simulate a feedforward SNN for a few steps per environment step and clear it before the next.
\swm~\cite{sun2025spikingwm} brings multicompartment neurons into the world model of DreamerV3 and evaluates it on DeepMind Control from pixels and on speech classification.
GRSN~\cite{qin2025grsn} aligns a gated recurrent spiking neuron with environment time and carries its state across steps for model-free RL in POMDPs.
Spiking model-based control has also been trained end to end with recurrent LIF networks~\cite{huebotter2025spiking}.
These works evaluate control and classification; on memory benchmarks, the resets they inherit limit memory to at most 16 steps (\cref{sec:rl}).

\paragraph{Spiking neurons with long memory.}
Adaptive thresholds~\cite{bellec2018lsnn,yin2021adaptive}, two-compartment neurons~\cite{zhang2024tclif}, heterogeneous dendritic time constants~\cite{zheng2024dhsnn} and resonate-and-fire dynamics~\cite{izhikevich2001resonate,higuchi2024brf,zhang2025drf} extend the memory of spiking neurons.
Removing the reset makes the membrane linear and parallelizable~\cite{fang2023psn}, and spiking state space layers attach spiking outputs to linear recurrences~\cite{shen2025spikingssm,bal2025pspikessm,fabre2025silif,stan2024learning}.
These neurons are trained and tested on offline sequence classification, where the network sees the whole sequence and is reset between samples.
A world model filters an unbounded stream step by step and also rolls its state forward in imagination; we run DH-SNN and TC-LIF in this setting as baselines.
\method is designed for it: memory is carried across environment steps only in dendrites that no spike resets, retention times are counted in environment steps, and the soma that produces spikes holds no state.
Biological dendrites act as computational subunits~\cite{london2005dendritic,poirazi2003pyramidal,larkum2013cellular,beniaguev2021single} and many neurons resonate below threshold~\cite{hutcheon2000resonance}; PDNs borrow both properties in functional form.
