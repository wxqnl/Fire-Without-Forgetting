\begin{abstract}
Embodied agents see only part of their world and must remember what has left their view.
World models give an agent this memory through a recurrent latent state, and spiking neural networks (SNNs) promise to run them with sparse binary events on low-power hardware.
We find that spiking world models forget within a few steps, although their neurons have long time constants.
Membrane potentials are cleared at every environment step and dendrites are reset by every somatic spike, so memory has to be re-encoded into binary spikes at each step and the time constants have no effect.
Causal interventions confirm this \emph{reset-induced amnesia}: a spiking world model fails to recall a cue 8 steps back whatever its time constants, and removing both resets restores memory up to 32 steps.
We propose \method, a spiking world model in which dendrites store and spikes communicate.
Each neuron keeps linear dendritic channels that are never reset and never receive spikes back, with time constants spanning 1 to 1000 environment steps and a write gain normalized across them.
Half of the channels resonate, so that their phase records how long ago an input arrived.
A stateless soma emits the only signal that leaves the neuron, a binary spike.
On BSuite memory length, \method is the only model, spiking or not, that solves 64-step recall, and it solves 101-step recall under the protocol of R2I, where DreamerV3 fails beyond 51 steps.
Its world model is the only one that recalls the input of exactly 32 steps ago on POPGym RepeatPrevious, and it uses 2.9$\times$ less energy per step than DreamerV3.
\end{abstract}
